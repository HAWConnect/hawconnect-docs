# Fehlerbehebung

## Der Kalenderlink funktioniert nicht

Importiere stattdessen eine heruntergeladene `.ics`-Datei. Bereits importierte Termine bleiben nach einer fehlgeschlagenen Aktualisierung erhalten. Siehe [Kalender](/de/docs/app/calendar).

## Die Anmeldung funktioniert nicht

Prüfe E-Mail-Adresse und Passwort. Ein neues Konto musst du zuerst mit dem 6-stelligen Code aus der E-Mail bestätigen; der Code ist 1 Stunde gültig. Hast du dein Passwort vergessen, wähle **Passwort vergessen?**. Die Anmeldung setzt einen verfügbaren Konto- und E-Mail-Dienst voraus. Der Gastmodus funktioniert ohne Konto.

## Der Speiseplan ist leer

Die Mensa kann geschlossen sein oder der Plan ist noch nicht veröffentlicht. Prüfe Datum und Mensa. Siehe [Essen](/de/docs/app/food).

## Die Karte lädt nicht

Kartenkacheln benötigen eine Internetverbindung. Prüfe deine Verbindung und lade die Seite neu.

## Einen Fehler gefunden?

Melde ihn als Issue auf GitHub. Siehe [Feedback](/de/docs/app/feedback).
