# Mitwirkende

HAWConnect entsteht durch Beiträge vieler Menschen. Die aktuelle Liste führt GitHub für jedes Repository:

- [App](https://github.com/hawconnect/hawconnect-app/graphs/contributors)
- [Backend](https://github.com/hawconnect/hawconnect-backend/graphs/contributors)
- [Console](https://github.com/hawconnect/hawconnect-console/graphs/contributors)
- [Docs](https://github.com/hawconnect/hawconnect-docs/graphs/contributors)

HAWConnect enthält Code, der aus der Anwendung Neuland Next und zugehörigen Upstream-Komponenten übernommen wurde; diese werden von Neuland Ingolstadt e.V. gepflegt.

Du willst auch mitmachen? Siehe [Mitmachen](/de/docs/contribute/contribute).
