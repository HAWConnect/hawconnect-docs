# Campus map

Open Map and search for a campus, an address or a building label such as **BT7**. Select a building or a search result to see its available details. Campus entries offer directions and links to the official campus plan and location information.

<AppScreenshots lang="en" screens={["map"]} note="Map data © OpenStreetMap contributors" />

The map covers Berliner Tor, Bergedorf, Finkenau and Armgartstraße.

## Good to know

- Map tiles need an internet connection.
- You can deny location permission and still browse the campuses; location is optional.
- Directions open in an external maps app.

For official information, see [HAW locations](https://www.haw-hamburg.de/en/university/locations/). Map data includes OpenStreetMap; keep the displayed attribution when you share screenshots.
