# Troubleshooting

## The calendar link fails

Import a downloaded `.ics` file instead. Events you already imported are kept after a failed refresh. See [Calendar](/en/docs/app/calendar).

## Sign-in does not work

Check your email address and password. A new account must be confirmed first with the 6-digit code from the email; the code is valid for 1 hour. If you forgot your password, choose **Forgot password?**. Signing in requires the account and email service to be available. Guest mode works without an account.

## The menu is empty

The mensa may be closed or the menu not published yet. Check the date and the mensa. See [Food](/en/docs/app/food).

## The map does not load

Map tiles need an internet connection. Check your connection and reload the page.

## Found a bug?

Report it as an issue on GitHub. See [Feedback](/en/docs/app/feedback).
