# About HAWConnect

HAWConnect is an open-source campus platform for HAW Hamburg, maintained by students for students.

The project is independent: HAW Hamburg does not run or endorse it, and no official connection is claimed.

The source code is on [GitHub](https://github.com/hawconnect) under the AGPL-3.0. You can read it, report bugs or contribute yourself, see [Contribute](/en/docs/contribute/contribute).
